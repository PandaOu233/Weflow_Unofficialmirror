# Weflow_Unofficialmirror

Unofficial backup mirror for archived Weflow release files.

## Repository contents

The `main` branch contains an archived copy of the original source repository.

The Windows `.exe` installer/application file is not stored directly in the repository file list because it is too large for normal GitHub file upload.

## Download `.exe`

Please download the `.exe` file from the **Releases** page:

👉 [Go to Releases](https://github.com/PandaOu233/Weflow_Unofficialmirror/releases)

Open the latest release, then download the `.exe` file from the **Assets** section.
